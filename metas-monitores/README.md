# Metas dos Monitores — Lemar

Painel estático para lançamento mensal de resultados, cálculo de remuneração, relatórios individuais e visão geral anonimizada.

## Publicação no GitHub Pages

Os arquivos `index.html`, `styles.css` e `app.js` podem ser publicados diretamente na raiz de um repositório com GitHub Pages habilitado.

## Dados e backup

Os dados são armazenados no `localStorage` do navegador. Use **Exportar backup** para baixar o JSON e **Importar backup** para restaurá-lo em outro navegador ou computador.

## PDF

Use **Exportar PDF individual** ou **Exportar PDF geral** e selecione **Salvar como PDF** na janela de impressão do navegador.
